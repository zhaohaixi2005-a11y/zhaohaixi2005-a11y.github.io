Project Gateway 01

Interface-Seeded De Novo Design of Symmetric Protein Assemblies

An RFdiffusion3-based framework for generating de novo scaffolds around predefined protein-protein interfaces under symmetric assembly constraints.

Jul 2026 - Present Research Intern

Academic Guidance

Institution LMU MUNICH
Supervisor
Prof. Alena Khmelinskaia
RFdiffusion3 Interface Seeding Symmetric Assemblies Designability

Project Overview

This project develops an RFD3 conditioning workflow that jointly preserves protein-protein interface geometry and target symmetric architecture during de novo backbone generation.

Research Motivation

Existing RFdiffusion-based interface-seeded design workflows can be limited by backbone generation and architecture constraints, especially for larger and higher-order assemblies.

Methods / Pipeline

  • Reproduced the original interface-seeded oligomer workflow using cyclic LHD101 assemblies as benchmarks.
  • Characterized seed preparation, symmetry placement, backbone generation, and downstream validation steps.
  • Built an RFD3-based conditioning strategy for predefined interface geometry and target symmetry.
  • Benchmarked interface-seed fidelity, scaffold diversity, designability, assembly formation, and competing oligomeric states.

My Contributions

  • Dissected the baseline RFdiffusion interface-seeded workflow to identify controllable design stages.
  • Implemented RFD3 conditioning logic for symmetry-aware scaffold generation around fixed interface seeds.
  • Defined comparative evaluation metrics for fidelity, diversity, and target assembly quality.

Key Outcomes

  • Established benchmark cases for interface-seeded symmetric assembly design.
  • Created a path to test whether RFD3 expands the accessible design space for higher-order assemblies.
  • Connected generative scaffold quality with assembly-level validation criteria.

Related Tools / Skills

  • RFdiffusion3, RFdiffusion workflow reproduction, symmetry-constrained design
  • Interface geometry analysis and scaffold quality benchmarking
  • Protein assembly design and computational validation
